# Getting Started

1. Clone the same repository; work in `feature/mobile`, `feature/web-ai`, or `feature/multimedia`.
2. Read the shared contracts and your folder's README.
3. Set up your own service dependencies; keep actual provider credentials in local `.env` files.
4. Implement your assigned module against fixtures in `shared/fixtures/`.
5. Run local tests before connecting to another teammate's service.
6. Open a reviewed pull request for integration. Never change the API contract silently.

The scaffold contains intentional placeholders. Docker Compose and MediaMTX still require secure real-service configuration before they can run the completed system.
